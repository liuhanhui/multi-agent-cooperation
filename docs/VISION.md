# Vision — Multi-Agent Cooperation

**One sentence:** We build the **platform layer above Agent CLIs** so multiple model families work as one team — not another multi-model chat box.

## Product stance

| Layer | Owns | Does not own |
|-------|------|--------------|
| Model | Reasoning, generation | Long-term memory, team discipline |
| Agent CLI | Tools, files, commands | Cross-agent routing, review protocol |
| **This platform** | Identity, collaboration, memory, SOP, audit | Being smarter than the model |

> Models set the ceiling. The platform sets the floor.

## What v1.0 must feel like

An operator expresses intent once. Agents with persistent identity route via `@mention`, hand off with structure, review across model families, remember decisions, and only escalate human approvals when needed.

## Non-goals (year one)

- Physical limbs / BLE devices
- Full enterprise IM action suites
- Convention-graph / eval philosophy completeness
- Cloud-hosted “browser cats” as first-class runtime
- Desktop installer as a v1.0 blocker (source + scripts ship first)

## Finish line

See `build-plan.md` acceptance criteria AC-P1–P11. Wave 5 = open-source parity release; Wave 6 is optional soul/polish.
